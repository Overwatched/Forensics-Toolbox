Vanliga artifacts

Snabbreferens för vanliga IT-forensiska artefaktplatser. Börja här — utöka efter behov.

Windows

ArtifactTypisk platsAnvändning
Prefetch C:\Windows\Prefetch\*.pf Programkörning, ungefärlig tid
Amcache C:\Windows\AppCompat\Programs\Amcache.hve Exekverade program, SHA-1
Event Logs C:\Windows\System32\winevt\Logs\ Inloggningar, processer, säkerhet
Registry (SYSTEM/SOFTWARE) C:\Windows\System32\config\ Systemkonfiguration, tjänster, USB
NTUSER.DAT C:\Users\<user>\NTUSER.DAT Användaraktivitet, Run-nycklar
$MFT C:\$MFT Filmetadata, tidslinje

iOS

ArtifactTypisk platsAnvändning
Photos.sqlite Media/PhotoData/Photos.sqlite (+ -wal, -shm) Fotobibliotek: tider, filnamn, bundle-ID. Använd iOS Queries.

Android

ArtifactTypisk platsAnvändning
MediaStore (external.db) /data/data/com.android.providers.media/databases/external.db Bilder/video på delad lagring. Använd Android Queries.
MediaStore module /data/data/com.android.providers.media.module/databases/external.db Nyare Android (scoped MediaProvider).
MediaStore (vissa extrakt) media/0/external.db Samma MediaStore, annan sökväg i extraktet.
UsageStats /data/system/usagestats/ App-användning (ofta XML, inte SQL). ALEAPP rekommenderas.
Google Camera /data/data/com.google.android.GoogleCamera/ App-privat kameradata.
Samsung Camera /data/data/com.sec.android.app.camera/ OEM-kamera. Gallery/CMH via ALEAPP.
